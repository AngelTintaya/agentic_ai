# agentic_ai

## GROQ
1. Create an account in groq: https://groq.com
2. Click in DEV CONSOLE
3. Create account
4. Click in API KEYS
5. Click in Create API KEY (name: agent_ai)
6. Copy the generated API KEY to .env file (as GROQ_API_KEY)

## Phidata
1. Go to phidata: https://www.phidata.com
2. Click Log In (Will create an account) -> Will end in a dashboard
3. Click in API KEY
4. Copy the API KEY

## When using Playground
1. Default Uvicorn running will not work in local
2. Go to phidata dashboard
3. Click in PlayGround
4. Click in Select an endpoint
5. It should show in green, which eands the endpoint is alive
